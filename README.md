# Home-Security-System
Embedded project

Developed an IoT-based medicine reminder and monitoring system to support elderly individuals living independently. The system helps users take their medicines on time while allowing caretakers or doctors to remotely manage medication schedules.

The device provides configurable daily reminders for regular medicine intake, along with additional alerts for upcoming doses and medicine refills. To support users who may find manual configuration difficult, a remote assistance feature was implemented using a SIM module, enabling caretakers or doctors to set or modify reminder schedules via SMS.

The system also includes a medicine box search feature, where sending a simple SMS command activates LEDs and a buzzer to help locate a misplaced medicine box. Overall, this project focuses on improving medication adherence, patient safety, and remote healthcare support for elderly users.

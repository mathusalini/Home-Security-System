# Home-Security-System
Embedded project

With the rise in home burglary, fire accidents, and unauthorized access, traditional security systems are no longer enough to ensure safety. They often lack real-time response, smart detection, and user verification. Our project aims to develop a smart security system using motion, flame, and vibration sensors, along with RFID technology, to provide automated, accurate, and efficient home protection. This system is designed to detect real threats, alert homeowners instantly, and allow access only to authorized individuals.
